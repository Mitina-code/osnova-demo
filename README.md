# ОСНОВА — демонстрационный прототип

Рабочее место сотрудника учреждения. Здесь опубликована одна роль — **цензор**.

**Открыть:** https://mitina-code.github.io/osnova-demo/

## Что это

Прототип показывает, как выглядит разбор смены, когда поток материалов заранее
разложен на три стопки по уровню риска:

- **зелёные** — признаков нарушения не найдено, подтверждаются группой;
- **оранжевые** — есть сомнение, разбираются по одному конвейером;
- **красные** — мотивировка формируется автоматически, сотрудник проверяет и подтверждает.

Решение по каждому материалу остаётся за человеком и записывается в журнал отдельной
записью — даже когда действие было групповым.

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | Страница-вход с подсказками, с чего начать |
| `prototype.html` | Сам прототип |
| `data-shift-normal.js` | Набор данных: обычный день, 200 материалов |
| `data-shift-peak.js` | Набор данных: пиковый день, 500 материалов |

Обычная веб-страница: открывается двойным кликом, серверов и установки не требует.

## Данные

Все имена, письма, события и оценки **вымышленные**, сгенерированы для демонстрации.
Совпадения с реальными людьми случайны. Персональных данных здесь нет.

Прототип ничего не сохраняет: перезагрузка возвращает смену к исходному состоянию.

## Границы прототипа

Это демонстрация интерфейса и логики работы, а не готовый продукт:

- оценка материалов имитируется, настоящего анализа содержания нет;
- данные не подключены к рабочим системам;
- входа по логину нет;
- реализована одна роль из четырёх.
